# 聆花文化小微企业ERP管理系统最终确认方案

## 项目概述

本方案旨在为非遗掐丝珐琅品牌——聆花文化，规划并建设一套**“小而精”**、高效易用且成本可控的综合性企业资源规划（ERP）管理系统。该系统将深度聚焦聆花文化的核心业务流程，包括掐丝珐琅作品的生产制作、非遗团建活动管理、日常咖啡店运营、产品与库存、销售与订单，以及人员薪酬和财务核算。通过数字化、自动化手段，系统将提升企业运营效率，优化资源配置，实现精细化管理，并为聆花文化这一非遗品牌的传承与商业发展提供坚实的数字化支撑。

**核心建设理念：**

- **功能聚焦：** 优先解决聆花文化当前最迫切的管理痛点，避免功能冗余和过度复杂化。
- **操作简便：** 确保系统界面直观友好，操作流程清晰流畅，最大程度降低员工的学习和使用成本。
- **适度自动化：** 在关键业务环节实现智能自动化，显著提升效率，同时保持系统易于理解和维护。
- **成本效益：** 在开发和后期运维中，注重投入产出比，确保系统的经济可行性。
- **可扩展性：** 系统架构将预留未来业务发展和功能模块扩展的接口，保障企业的长期发展需求。

## 项目背景与目标

聆花文化作为非遗掐丝珐琅的代表品牌，业务涵盖传统工艺生产、文化体验活动、文创产品销售及衍生业务。随着业务规模的逐步扩大，现有管理模式在生产协同、库存追踪、客户管理、销售结算及财务核算等方面面临挑战。

本ERP系统旨在解决以下关键问题：

1. 提升生产流程的自动化与可视化水平，实现订单到生产的顺畅流转。
2. 优化非遗团建活动的管理效率，包括客户、场地、人员和预算的精细化管控。
3. 实现多渠道销售的统一管理和订单快速响应。
4. 建立实时、准确的库存管理体系，减少积压与缺货。
5. 构建自动化薪酬核算机制，确保人员成本管理的精准性。
6. 提供清晰的财务数据和报表，支持企业经营决策。
7. 沉淀非遗知识与作品档案，提升品牌核心价值。

## 功能模块详细设计

### 一、生产与制作管理模块

本模块将简化对掐丝点蓝和配饰制作全过程的精细化管理，聚焦核心流程，确保数据准确与流程透明。

1. **制作任务管理：**
    - **掐丝点蓝制作：** 提供原材料选择与自动扣减库存功能；制作工费记录（含委外加工需求联动、应付账款同步）；支持制作过程照片上传。
    - **配饰制作：** 允许选择半成品并自动扣减库存；管理配饰材料消耗与自动扣减库存；记录配饰工费并自动计入制作人薪酬核算；支持过程照片上传。
2. **订单驱动生产流转：**
    - **智能工单生成与匹配：** 销售订单提交时，系统实时分析产品清单，智能匹配底胎库存（广州原料仓、崇左生产基地仓）和制作服务，并自动生成标准化生产工单。若库存不足或需委外加工，自动生成崇左委外采购清单并推送至采购模块，同步触发底胎调拨指令。
    - **底胎出库与崇左生产触发：** 底胎调拨指令自动生成待出库单经项目负责人审核后，系统根据底胎来源自动生成广州原料仓出库任务或采购订单（委外直发崇左），并同步物流信息。崇左负责人审核到货底胎后，系统自动激活崇左生产任务，并实时推送至崇左生产看板。
3. **极简报工与过程追踪：**
    - **崇左极简报工：** 崇左负责人通过生产看板派单。制作人员通过移动端**拍照上传半成品**并确认清单，点击“完工确认”即可完成报工，系统自动记录完工信息。
    - **半成品自动回调与物流追踪：** 完工确认后系统自动生成待打包清单，崇左负责人填报物流单号后，系统可自动对接物流公司接口追踪物流状态，更新在途信息。
4. **后工智能调度：**
    - **半成品入仓触发：** 广州仓通过扫码收货，经人工质检（可拍照记录问题）合格后，系统自动将半成品入库，并根据产品需求自动生成后工（配饰/装裱）任务。
    - **后工计费自动化：** 后工人员领取并完成任务报工后，系统自动匹配预设“产品服务”价格并计算加工费，自动记录到员工名下并汇总至财务模块。

### 二、非遗团建管理模块

本模块提供团建活动一站式解决方案，全面提升团建业务的专业性和效率。

1. **客户管理：** 联动统一客户模块，管理团建客户信息。
2. **活动时间管理：** 灵活选择活动日期，智能检测场地、讲师、助理的时间冲突并预警；提供可视化活动时间轴及定制化提醒功能。
3. **场地管理：** 记录场地信息、实时状态、租赁费用，支持日历视图展示。
4. **人数管理：** 统计确认/实际到场人数，支持人员分组与人数限制。
5. **人员配置管理：** 管理项目负责人、讲师（含专业领域、等级、费用）和助理（含协助能力、工作分配），确保合理排班。
6. **预算管理表：** 自动核算活动收入预算、支出预算，并实时计算预期利润。
7. **其他要求管理：** 记录特殊需求（饮食、无障碍）、定制化服务、安全要求和技术支持。
8. **服务内容扩展：** 定义标准服务包和各项增值服务，支持灵活组合与定价。

### 三、员工与薪酬管理模块

本模块将员工基础信息与薪酬管理合并，实现人员管理的集中与薪酬核算的自动化。

1. **员工档案：** 管理员工基础信息（姓名、身份证、联系方式、入职、职位），并记录专业技能、工种，支持精细化的薪酬结构配置。
2. **薪酬自动计算与发放：** 系统每月自动归集生产、销售、团建、排班等模块的各项数据，根据薪酬结构自动计算生成薪酬详情清单，支持简易审核。自动生成电子薪资条和发放记录，并提供员工自助历史查询及管理层查询功能。审核通过的薪酬数据自动同步至财务模块。

### 四、排班管理模块

本模块提供直观、灵活的排班功能，尤其适用于聆花掐丝珐琅馆的日常运营。

1. **聆花掐丝珐琅馆排班：** 支持班次设置，提供清晰的日历视图排班界面，支持点击、拖拽和批量选择日期进行排班。可清晰显示已排班人员名字，支持多人同班，并智能提示时间冲突。支持排班表导出。

### 五、咖啡店运营管理模块

本模块将独立管理“印象咖咖啡店”的日常运营数据，与相关模块联动，简化数据分析。

1. **咖啡店日常管理：** 支持每日销售总额手动录入（预留未来POS系统集成接口）。咖啡店提成将根据排班记录自动均分给值班员工，并自动计入薪酬。咖啡店采购需求直接关联至主采购模块，并支持独立筛选显示。
2. **简易数据分析：** 提供销售记录列表、采购内容金额列表、提成金额和简化的利润分析表。

### 六、渠道与客户关系管理模块

本模块将渠道管理和客户管理整合，聚焦营销和销售流程，为小微企业提供更集中的客户视图。

1. **客户档案：** 集中管理散客、团建客户、渠道客户、合作伙伴等所有客户信息，记录消费与跟进历史，支持自定义客户标签。
2. **渠道信息管理：** 详细记录渠道档案、合作类型、联系人、联系方式、地址、银行信息等，并可配置差异化定价、拿货押金、结算方式及推广支持。
3. **渠道库存与销售追踪：** 为广西生产基地仓、深圳景之蓝仓、各代销渠道仓设立独立虚拟仓库，实现发货与虚拟仓库存的自动更新。支持简易销售数据录入，并提供库存预警与补货提醒。
4. **渠道对账结算：** 支持收集各渠道月度销售数据，自动生成对账单并高亮显示差异，对账单确认无误后自动生成结算单据并同步财务。

### 七、产品与服务管理模块

本模块将所有可销售的产品和服务集中管理，作为系统核心数据的基础。

1. **产品与服务信息结构：** 管理艺术品序号、条形码、名称、分类、尺寸、单位、**实时库存**等基础信息。详细记录工艺、底胎材质、配饰、包装装裱、产品标签、产品描述（或服务描述）。支持多图片上传。实现多维度价格体系：**成本价（自动核算）**、零售价、渠道价、服务定价。
2. **功能需求与仓库架构：** 提供列表页多视图，支持双击快速修改产品/服务名称、尺寸、价格。系统将完全按照聆花文化提供的实体仓库（广州原料仓、半成品仓、成品仓）和虚拟仓库（广西生产基地仓、各渠道仓）架构进行数字化建模。

### 八、库存管理功能

本模块提供全面、实时的库存管理能力，确保库存数据的准确性和透明度。

1. **库存可视化与查询：** 直观展示产品图片、名称、库存量、所属仓库。支持按仓库、分类、供应商、名称、条形码、产品标签等多维度组合筛选。
2. **库存预警：** 设置最低库存量，系统自动发送提醒，触发采购或生产补货流程。
3. **批次管理：** 记录产品批次信息、入库日期、供应商、生产日期等，实现基本追溯。
4. **库存盘点：** 支持定期盘点和抽样盘点，生成盘点差异报告。
5. **出入库与调拨：** 提供标准的出库单、入库单、调拨单界面，支持扫码操作，所有操作均自动更新库存数量并保留完整历史记录。

### 九、采购与供应商管理模块

本模块将供应商信息与采购流程整合，形成统一的采购管理中心。

1. **供应商档案：** 分类管理各类供应商（底胎、装裱、配饰、包装、生产基地等），记录基础信息、合作条款，并支持简易内部评价。
2. **采购业务流程：** 采购需求可由库存预警、生产计划需求、销售订单需求或手动触发。支持简易的采购申请与审批流程。系统可记录询价明细，审批通过后自动生成采购订单并支持发送供应商，跟踪订单状态。实现收货检验（含拍照）与扫码入库，并通过发票核对自动生成付款申请单并流转至财务。

### 十、销售与订单管理模块

本模块将全面管理销售渠道，并自动化订单处理流程，突出简便性。

1. **多渠道销售：** 支持线下零售（提供简易开单界面并预留POS系统集成接口）、手作体验/课程销售（预约与结算）、渠道销售（发货与结算），并预留电商平台标准API接口（如淘宝、微店）。
2. **订单处理流程：** 订单创建时提供清晰产品列表（含图片、库存），自动匹配价格。系统实时检查库存，若不足则提醒或转生产排期。支持简易订单审核。订单执行包括生产/备货触发、质检、发货。收款管理包括发票申请、收款记录与应收核销。同时提供简易售后服务记录功能。

### 十一、财务管理模块

本模块将实现基本的财务核算、成本控制和报表分析，重点在于实用性与决策支持。

1. **应收应付管理：** 自动生成应收账款（销售订单、渠道结算、团建项目等）与应付账款（采购、薪酬、委外加工等），支持账龄分析和催收提醒。
2. **成本核算体系：** 自动归集产品成本构成（直接材料、直接人工、委外加工费、制造费用分摊）。初期优先采用实际成本法和标准成本法。
3. **财务报表：** 自动化生成核心财务报表，包括损益表、资产负债表、现金流量表，以及详细的产品成本分析表。

### 十二、聆花文化特有需求与特色功能

本模块旨在满足聆花文化作为非遗品牌和文创企业的独特管理与品牌建设需求。

1. **非遗知识与作品档案：** 建立非遗掐丝珐琅工艺知识库（工艺流程、历史、文化寓意）。记录高价值作品从设计、材料采购、制作（关联制作人、工时）、质检、装裱、销售的完整生命周期信息，并可选择为作品生成唯一的数字鉴证码或二维码。详细记录大师/手艺人档案及其作品、成就。
2. **定制化订单管理：** 提供定制需求记录界面（设计元素、材质、尺寸、主题），支持上传设计稿、效果图及记录客户确认/修改意见。审批通过后，自动生成特殊的生产工单。
3. **营销与活动推广（简易）：** 简易记录和管理各类营销活动（时间、地点、参与人数、预算与实际花费）。提供简易表单收集客户对产品、服务、活动的反馈建议，并预留社群互动接口。

### 十三、系统设置与管理模块

本模块提供系统级的配置和管理功能，但更侧重小微企业的易用性与基础运维。

1. **基础设置：** 管理公司信息、财务年度、默认单位、默认仓库等基本配置。
2. **用户与权限：** 提供精简的角色与权限管理，预设常用角色（如管理员、仓管、销售、制作人员、财务等），并可为用户分配对应权限。
3. **数据导入导出：** 支持各模块数据批量导入导出（Excel、PDF）。
4. **操作日志：** 记录关键操作日志，便于问题追溯。
5. **系统维护：** 提供基本的数据库备份与恢复功能，接口管理简化为仅显示已集成或预留接口的状态。

### 十四、信息工具

本模块提供系统内置的沟通和协作工具，提升团队内部的协作效率。

1. **通知功能：** 提供系统内部消息、邮件，用于重要事件提醒。
2. **待办功能：** 自动生成用户的待处理任务列表。
3. **邮件功能：** 支持通过系统向客户、供应商发送邮件，并保留发送记录。
