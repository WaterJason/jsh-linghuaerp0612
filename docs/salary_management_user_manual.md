## 🎯 系统概述

### 系统简介
jshERP薪酬管理模块是专为珐琅馆等手工艺企业设计的薪酬管理系统，支持复杂的薪酬结构和灵活的计算规则。

### 主要功能
- **薪酬档案管理**: 员工薪酬信息维护
- **薪酬计算**: 自动化薪酬计算引擎
- **薪酬发放**: 薪酬发放流程管理
- **薪资查询**: 薪资数据查询统计
- **系统配置**: 薪酬项目和系统参数配置

### 用户角色
- **薪酬管理员**: 拥有所有薪酬管理权限
- **薪酬专员**: 负责薪酬档案维护和计算
- **财务人员**: 负责薪酬发放和财务处理
- **普通员工**: 查看个人薪资信息

## 🔧 功能介绍

### 1. 薪酬档案管理
管理员工的基本薪酬信息，包括：
- 员工基本信息（姓名、部门、职位等）
- 日薪标准设置
- 薪酬状态管理
- 薪酬项目配置

### 2. 薪酬计算
自动计算员工月度薪酬，支持：
- 固定薪酬：日薪 × 工作天数
- 销售提成：销售额 × 提成比例
- 生产提成：完成件数 × 单件费用
- 培训提成：培训收入 × 提成比例
- 津贴补助：各类津贴和补助

### 3. 薪酬发放
管理薪酬发放流程，包括：
- 发放记录创建
- 发放状态跟踪
- 薪资条生成
- 财务凭证管理

### 4. 薪资查询
提供多维度薪资查询，支持：
- 个人薪资查询
- 部门薪资统计
- 月度薪资趋势
- 薪资明细分析

## 📋 操作指南

### 登录系统
1. 打开jshERP系统
2. 输入用户名和密码
3. 点击"登录"按钮
4. 在左侧菜单中找到"薪酬管理"

### 薪酬档案管理操作

#### 新增员工薪酬档案
1. 进入"薪酬管理" → "薪酬档案"
2. 点击"新增薪酬档案"按钮
3. 填写员工基本信息：
   - 员工姓名（必填）
   - 身份证号
   - 联系电话
   - 邮箱地址
   - 所属部门
   - 职位信息
   - 入职时间
   - 日薪标准（必填）
4. 点击"保存"按钮

#### 配置员工薪酬结构
1. 在薪酬档案列表中找到目标员工
2. 点击"配置薪酬"按钮
3. 选择适用的薪酬项目：
   - 勾选需要的薪酬项目
   - 设置个人定制比例（如有）
   - 设置个人定制金额（如有）
   - 设置生效时间和失效时间
4. 点击"保存配置"

#### 修改薪酬档案
1. 在薪酬档案列表中找到目标员工
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"保存"按钮

### 薪酬计算操作

#### 执行月度薪酬计算
1. 进入"薪酬管理" → "薪酬计算"
2. 设置计算参数：
   - 选择计算月份
   - 选择员工范围（全部员工/按部门/自定义）
   - 如选择按部门，需选择具体部门
3. 点击"开始计算"按钮
4. 等待计算完成，查看计算进度
5. 计算完成后查看计算结果

#### 审批薪酬计算
1. 在薪酬计算列表中查看待审批记录
2. 点击"详情"按钮查看计算明细
3. 确认计算结果无误后：
   - 点击"审批通过"按钮
   - 或点击"审批拒绝"并填写拒绝原因
4. 填写审批意见
5. 确认审批操作

#### 批量审批
1. 在薪酬计算列表中勾选多条记录
2. 点击"批量审批"或"批量拒绝"按钮
3. 填写审批意见
4. 确认批量操作

### 薪酬发放操作

#### 创建发放记录
1. 进入"薪酬管理" → "薪酬发放"
2. 点击"创建发放记录"按钮
3. 选择已审批的薪酬计算记录
4. 选择发放方式：
   - 银行转账
   - 现金发放
   - 其他方式
5. 点击"确定"创建发放记录

#### 确认发放
1. 在发放记录列表中找到待发放记录
2. 点击"确认发放"按钮
3. 确认发放信息无误
4. 点击"确定"完成发放

#### 生成薪资条
1. 在发放记录列表中找到已发放记录
2. 点击"生成薪资条"按钮
3. 系统自动生成PDF格式薪资条
4. 可下载或打印薪资条

### 薪资查询操作

#### 个人薪资查询
1. 进入"薪酬管理" → "薪资查询"
2. 选择查询月份
3. 点击"查询"按钮
4. 查看个人薪资详情和明细

#### 管理员薪资查询
1. 进入"薪酬管理" → "薪资查询"
2. 设置查询条件：
   - 员工姓名
   - 部门
   - 查询月份
3. 点击"查询"按钮
4. 查看薪资统计表格和图表

### 系统配置操作

#### 薪酬项目配置
1. 进入"薪酬管理" → "薪酬配置"
2. 在左侧"薪酬项目配置"区域：
   - 点击"新增薪酬项目"添加新项目
   - 点击"编辑"修改现有项目
   - 点击"启用/禁用"切换项目状态
3. 填写项目信息：
   - 项目编码（唯一）
   - 项目名称
   - 项目类型（固定薪酬/提成/津贴）
   - 计算公式
   - 默认比例或基础金额
   - 项目描述
4. 保存配置

#### 系统参数配置
1. 在右侧"系统配置"区域设置：
   - 默认工作天数/月
   - 计算超时时间
   - 批量计算大小
   - 审批流程开关
   - 缓存配置参数
2. 点击"保存配置"

## ❓ 常见问题

### Q1: 为什么无法看到薪酬管理菜单？
**A**: 请检查以下几点：
1. 确认账号是否有薪酬管理权限
2. 联系管理员分配相应权限
3. 清除浏览器缓存后重新登录

### Q2: 薪酬计算结果不准确怎么办？
**A**: 请按以下步骤检查：
1. 确认员工薪酬档案信息是否正确
2. 检查薪酬项目配置是否准确
3. 确认基础数据（销售额、工作天数等）是否正确
4. 如仍有问题，请联系技术支持

### Q3: 如何修改已审批的薪酬计算？
**A**: 已审批的薪酬计算不能直接修改，需要：
1. 联系有权限的管理员
2. 将状态改为"拒绝"
3. 重新进行薪酬计算
4. 重新提交审批

### Q4: 薪资条丢失了怎么办？
**A**: 可以重新生成：
1. 进入"薪酬发放"页面
2. 找到对应的发放记录
3. 点击"查看薪资条"重新生成

### Q5: 如何导出薪资数据？
**A**: 在各个页面都有导出功能：
1. 点击"导出"按钮
2. 选择导出格式（Excel/PDF）
3. 确认导出范围
4. 下载导出文件
