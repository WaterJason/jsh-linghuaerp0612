# 掐丝珐琅馆模块 - 快速上手指南

## 🚀 5分钟快速体验

### 第一步：环境准备
确保您的系统已安装以下环境：
- ✅ Java 1.8+
- ✅ MySQL 5.7+
- ✅ Redis 6.0+
- ✅ Node.js 14.x+

### 第二步：一键部署
```bash
# 进入项目目录
cd /path/to/jshERP-0612-Cursor

# 执行自动化部署脚本
chmod +x jshERP-boot/scripts/deploy-cloisonne-module.sh
./jshERP-boot/scripts/deploy-cloisonne-module.sh
```

### 第三步：访问系统
- 🌐 **前端地址**：http://localhost:8080
- 🔑 **默认账户**：admin / 123456
- 📱 **移动端**：支持响应式访问

## 📋 功能导览

### 1. 总览仪表板 `/cloisonne/dashboard`
**核心功能**：
- 📊 实时运营指标监控
- 👥 当前值班人员信息
- ⚡ 快速操作面板
- 📈 销售趋势可视化

**快速操作**：
1. 点击"录入咖啡店销售"→填写销售数据→自动生成财务记录
2. 点击"POS销售"→选择商品→创建订单→更新库存
3. 点击"安排排班"→选择员工和时间→智能冲突检测

### 2. 排班管理 `/cloisonne/schedule`
**三种视图模式**：
- 🗓️ **日历视图**：拖拽排班，直观操作
- 📋 **列表视图**：批量管理，筛选排序
- 📊 **统计视图**：工时分析，出勤统计

**常用操作**：
1. **创建排班**：点击"新增排班"→选择员工→设置班次→保存
2. **批量操作**：选择多条记录→批量请假/调班/删除
3. **查看统计**：切换到统计视图→查看员工工时和出勤率

### 3. 咖啡店管理 `/cloisonne/coffee`
**主要功能**：
- 💰 日销售数据录入
- 📸 销售凭证上传
- 📊 销售趋势分析
- 💳 自动财务记录

### 4. POS销售 `/cloisonne/pos`
**完整流程**：
- 🛍️ 商品选择→🛒 购物车→💳 支付→📦 库存更新

## 🎯 典型使用场景

### 场景1：每日开馆前的排班安排
```
1. 登录系统 → 进入排班管理
2. 查看今日值班安排 → 确认人员到位
```

```
3. 完成支付 → 系统自动更新库存
4. 生成销售单据 → 记录财务收入
```

### 场景4：员工任务分配和跟踪
```
1. 进入任务管理 → 创建新任务
2. 分配给相关员工 → 设置优先级和截止时间
3. 员工接收任务 → 更新执行进度

```

## 🛠️ 故障排除

### 常见问题及解决方案

#### 1. 登录后看不到掐丝珐琅馆菜单
**原因**：用户权限未配置
**解决**：
```sql
-- 检查用户权限
SELECT * FROM jsh_user_business WHERE key_id = '用户ID';

-- 分配权限
INSERT INTO jsh_user_business (type, key_id, value, btn_str, tenant_id, delete_flag) 
VALUES ('UserRole', '用户ID', '10,1001', '1,7', '租户ID', '0');
```

#### 2. 排班创建失败
**原因**：可能是数据验证失败或权限不足
**解决**：
1. 检查必填字段是否完整
2. 确认用户有新增权限（按钮权限包含"1"）
3. 检查是否存在时间冲突

#### 3. 图表不显示
**原因**：数据加载失败或ECharts未正确初始化
**解决**：
1. 刷新页面重新加载
2. 检查浏览器控制台错误信息
3. 确认数据接口返回正常

#### 4. 性能较慢
**原因**：数据量大或数据库性能问题
**解决**：
```bash
# 使用性能监控脚本检查
./jshERP-boot/scripts/monitor-cloisonne-performance.sh -o

# 查看数据库性能
./jshERP-boot/scripts/monitor-cloisonne-performance.sh -s
```

## 📊 性能优化建议

### 1. 数据库优化
```sql
-- 添加常用查询索引
CREATE INDEX idx_schedule_date_employee ON jsh_cloisonne_schedule(tenant_id, schedule_date, employee_id);
CREATE INDEX idx_coffee_sales_date ON jsh_cloisonne_coffee_sales(tenant_id, sales_date);

-- 定期优化表
```

### 2. 缓存配置
```yaml
# Redis缓存配置优化
spring:
  redis:
    timeout: 2000ms
    lettuce:
      pool:
        max-active: 20
        max-wait: -1ms
        max-idle: 10
        min-idle: 5
```
