# 掐丝珐琅馆模块部署指南

## 📋 部署概述

掐丝珐琅馆模块是jshERP的业务扩展模块，提供排班管理、咖啡店销售、POS销售、任务管理等功能。本指南将详细说明如何在现有jshERP系统中部署该模块。

---

## 🔧 环境要求

### 后端环境
- **Java**: JDK 1.8+
- **Spring Boot**: 2.x
- **MySQL**: 5.7.33+
- **Redis**: 6.2.1+
- **Maven**: 3.6+

### 前端环境
- **Node.js**: 14.x+
- **Vue.js**: 2.7.16
- **Ant Design Vue**: 1.5.2
- **npm/yarn**: 最新版本

---

## 📦 部署步骤

### 第一步：数据库初始化

1. **执行数据库脚本**
```sql
-- 在jshERP数据库中执行
source /path/to/jshERP-boot/docs/cloisonne_module_tables.sql;
```

2. **验证表创建**
```sql
-- 检查表是否创建成功
SHOW TABLES LIKE 'jsh_cloisonne_%';

-- 应该看到以下7张表：
-- jsh_cloisonne_config
-- jsh_cloisonne_schedule  
-- jsh_cloisonne_coffee_sales
-- jsh_cloisonne_pos_product
-- jsh_cloisonne_pos_order
-- jsh_cloisonne_pos_order_item
-- jsh_cloisonne_task
```

3. **权限菜单配置**
```sql
-- 检查权限菜单是否正确插入
SELECT * FROM jsh_function WHERE number LIKE '10%';
```

### 第二步：后端代码部署

1. **复制Java文件**
```bash
# 复制实体类
cp -r src/main/java/com/jsh/erp/datasource/entities/Cloisonne* /path/to/jshERP-boot/src/main/java/com/jsh/erp/datasource/entities/

# 复制Mapper接口
cp -r src/main/java/com/jsh/erp/datasource/mappers/Cloisonne* /path/to/jshERP-boot/src/main/java/com/jsh/erp/datasource/mappers/

# 复制VO类
cp -r src/main/java/com/jsh/erp/datasource/vo/Cloisonne* /path/to/jshERP-boot/src/main/java/com/jsh/erp/datasource/vo/

# 复制Service层
cp -r src/main/java/com/jsh/erp/service/cloisonne /path/to/jshERP-boot/src/main/java/com/jsh/erp/service/

# 复制Controller层
cp -r src/main/java/com/jsh/erp/controller/Cloisonne* /path/to/jshERP-boot/src/main/java/com/jsh/erp/controller/
```

2. **复制XML映射文件**
```bash
# 复制MyBatis映射文件
cp -r src/main/resources/mapper_xml/cloisonne /path/to/jshERP-boot/src/main/resources/mapper_xml/
```

3. **更新MyBatis配置**
```xml
<!-- 在 mybatis-config.xml 中添加 -->
<mappers>
    <mapper resource="mapper_xml/cloisonne/CloisonneScheduleMapperEx.xml"/>
    <mapper resource="mapper_xml/cloisonne/CloisonneCoffeeSalesMapperEx.xml"/>
    <mapper resource="mapper_xml/cloisonne/CloisonnePosOrderMapperEx.xml"/>
    <mapper resource="mapper_xml/cloisonne/CloisonneTaskMapperEx.xml"/>
</mappers>
```

4. **编译和打包**
```bash
cd /path/to/jshERP-boot
mvn clean compile
mvn package -DskipTests
```

### 第三步：前端代码部署

1. **复制Vue组件**
```bash
# 复制页面组件
cp -r src/views/cloisonne /path/to/jshERP-web/src/views/

# 复制API接口
cp src/api/cloisonne.js /path/to/jshERP-web/src/api/

# 复制路由配置
cp src/router/modules/cloisonne.js /path/to/jshERP-web/src/router/modules/
```

2. **更新路由配置**
```javascript
// 在 /path/to/jshERP-web/src/router/index.js 中添加
import cloisonneRouter from './modules/cloisonne'

// 在 routes 数组中添加
const routes = [
  // ... 其他路由
  cloisonneRouter
]
```

3. **安装依赖和构建**
```bash
cd /path/to/jshERP-web
npm install
npm run build
```

### 第四步：权限配置

1. **管理员权限配置**
```sql
-- 为管理员角色分配掐丝珐琅馆权限
INSERT INTO jsh_user_business (type, key_id, value, btn_str, tenant_id, delete_flag) 
VALUES ('UserRole', '管理员角色ID', '10,1001,1002,1003,1004,1005,1006', '1,2,3,7', '租户ID', '0');
```

2. **用户权限分配**
```sql
-- 为特定用户分配权限
INSERT INTO jsh_user_business (type, key_id, value, btn_str, tenant_id, delete_flag) 
VALUES ('UserRole', '用户ID', '10,1001,1002', '1,7', '租户ID', '0');
```

### 第五步：服务启动

1. **启动后端服务**
```bash
cd /path/to/jshERP-boot
java -jar target/jshERP-boot-*.jar
```

2. **启动前端服务**（开发环境）
```bash
cd /path/to/jshERP-web
npm run serve
```

3. **生产环境部署**
```bash
# 使用Nginx部署前端静态文件
cp -r dist/* /var/www/html/jsherp/
```

## 🚨 常见问题排查

### 问题1：页面404错误
**原因**: 路由配置未正确加载
**解决方案**:
```javascript
// 检查 router/index.js 是否正确导入
import cloisonneRouter from './modules/cloisonne'
```

### 问题2：API接口500错误
**原因**: MyBatis映射文件未加载
**解决方案**:
```xml
<!-- 检查 mybatis-config.xml 配置 -->
<mapper resource="mapper_xml/cloisonne/CloisonneScheduleMapperEx.xml"/>
```

### 问题3：权限验证失败
**原因**: 用户权限未正确配置
**解决方案**:
```sql
-- 检查用户权限配置
SELECT * FROM jsh_user_business WHERE key_id = '用户ID';
```

### 问题4：数据库连接错误
**原因**: 数据库表未创建或字段不匹配
**解决方案**:
```sql
-- 重新执行建表脚本
source cloisonne_module_tables.sql;
```

## 📊 性能优化建议

### 数据库优化
1. **索引优化**
```sql
-- 为常用查询字段添加索引
CREATE INDEX idx_schedule_date_employee ON jsh_cloisonne_schedule(schedule_date, employee_id);
CREATE INDEX idx_coffee_sales_date ON jsh_cloisonne_coffee_sales(sales_date);
CREATE INDEX idx_pos_order_date ON jsh_cloisonne_pos_order(order_date);
```

2. **分页查询优化**
```sql
-- 使用LIMIT进行分页，避免大量数据查询
SELECT * FROM jsh_cloisonne_schedule 
WHERE tenant_id = ? AND delete_flag = '0'
ORDER BY schedule_date DESC 
LIMIT 20 OFFSET 0;
```

### 前端优化
1. **组件懒加载**
```javascript
// 使用动态导入实现懒加载
component: () => import('@/views/cloisonne/Schedule')
```

2. **图片资源优化**
```javascript
// 使用CDN或压缩图片
const avatarUrl = `https://cdn.example.com/avatars/${userId}.jpg`
```

## 🔒 安全配置

### 1. API安全
```java
// 在Controller中添加权限验证
@PreAuthorize("hasPermission('1002', 'READ')")
public BaseResponseInfo getScheduleList() {
    // ...
}
```

### 2. 数据安全
```sql
-- 确保所有查询都包含租户ID过滤
WHERE tenant_id = #{tenantId} AND delete_flag = '0'
```

### 3. 前端安全
```javascript
// 路由守卫验证权限
router.beforeEach((to, from, next) => {
  if (to.meta.permission && !hasPermission(to.meta.permission)) {
    next('/403')
  } else {
    next()
  }
})
```
